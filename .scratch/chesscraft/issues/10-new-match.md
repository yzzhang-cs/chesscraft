# 10: New match (return to the army-select menu)

**What to build:** A player can abandon the current match and return to the army-select menu to start a fresh match, choosing each side's army anew.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] A New match control is available during the match and after it ends.
- [ ] Choosing it returns to the army-select menu with the Side 1 and Side 2 army pickers.
- [ ] Starting from that menu begins a fresh match: the board shows the chosen openings, Side 1 moves first, and there is no undo history or win banner.
- [ ] The previous board, undo history, and win banner are discarded.
